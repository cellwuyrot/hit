# ТОПХИТ — Интернет-магазин товаров

> **Внимание:** эта версия не установлена на рабочем сайте и проверена только на тестовой базе. Перед обновлением прочитайте `docs/UPDATE_2026-11.md`, сделайте согласованную резервную копию базы и всех изображений и проверьте восстановление на отдельном стенде. Не запускайте seed на рабочей базе.

Полнофункциональный интернет-магазин с админ-панелью для управления товарами, категориями и рекламным слайдером.

## Стек технологий

- **Next.js 16** (App Router, Turbopack)
- **TypeScript**
- **Tailwind CSS 4**
- **Prisma 7** + SQLite (адаптер better-sqlite3)
- **JWT** аутентификация для админ-панели

## Возможности

### Для покупателей
- Главная страница со слайдером рекламных баннеров
- Каталог товаров с фильтрами (цена, тип, бренд, цвет)
- Карточки товаров с ценой, наличием, фото
- Категории товаров с подсчётом количества
- Видео о товаре с YouTube в карточке товара (блок над отзывами)
- Сортировка (по популярности, алфавиту, цене)
- Адаптивная вёрстка для мобильных устройств

### Админ-панель (`/admin`)
- Авторизация по логину/паролю
- Управление категориями (CRUD)
- Управление товарами (CRUD)
- Управление слайдами рекламного баннера (CRUD)
- Раздел «Видео»: привязка роликов YouTube к товарам по ссылке, поиск товара по названию/артикулу/категории, предпросмотр плеера, порядок показа, скрытие видео

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone <url>
cd shop

# 2. Установить зависимости
npm install

# 3. Скопировать .env файл
cp .env.example .env

# 4. Сгенерировать Prisma клиент и создать БД
npx prisma generate
npx prisma migrate dev

# 5. Только для новой тестовой БД: задайте уникальные данные первого администратора
# и заполните тестовыми данными. Не выполняйте на рабочем сервере.
ADMIN_INITIAL_USERNAME=your-admin ADMIN_INITIAL_PASSWORD='a-unique-long-password' npm run seed

# 6. Запустить dev-сервер
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Вход в админ-панель

- **URL:** [http://localhost:3000/admin](http://localhost:3000/admin)
- Используйте единый вход на `/account` с логином администратора или email покупателя.
- Для новой тестовой базы задайте `ADMIN_INITIAL_USERNAME` и `ADMIN_INITIAL_PASSWORD` при seed (не менее 12 символов). Существующие пароли и учётные записи не изменяются.

## Структура проекта

```
src/
├── app/
│   ├── admin/          # Админ-панель
│   ├── catalog/        # Каталог и категории
│   ├── api/            # API маршруты
│   │   ├── admin/      # CRUD API (авторизация, категории, товары, слайдер)
│   │   ├── categories/ # Публичный API категорий
│   │   ├── products/   # Публичный API товаров
│   │   └── slider/     # Публичный API слайдера
│   ├── layout.tsx      # Корневой layout
│   └── page.tsx        # Главная страница
├── components/         # React компоненты
│   ├── Header.tsx      # Шапка сайта
│   ├── Footer.tsx      # Подвал
│   ├── HeroSlider.tsx  # Слайдер баннеров
│   ├── ProductCard.tsx # Карточка товара
│   └── CatalogFilters.tsx # Фильтры каталога
├── lib/                # Утилиты
│   ├── prisma.ts       # Prisma клиент
│   └── auth.ts         # JWT авторизация
└── generated/          # Сгенерированный Prisma клиент

prisma/
├── schema.prisma       # Схема БД
├── seed.ts             # Начальные данные
└── migrations/         # Миграции
```
